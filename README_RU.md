# Видеоплеер с автопропуском

Это автономное приложение видеоплеера, которое позволяет воспроизводить видео с настраиваемыми правилами пропуска. Работает локально на вашем компьютере и требует всего лишь однократного запуска скрипта.

## Особенности

- Локальный веб-интерфейс видеоплеера с использованием HTML5
- Поддержка плейлистов с навигацией «следующий/предыдущий»
- Настраиваемые правила пропуска для каждого видео (определенные временные диапазоны для пропуска)
- Визуальные маркеры на таймлайне, показывающие области пропуска
- Поддержка форматов плейлистов JSON и TXT
- Полностью автономная работа после первоначальной настройки

## Как использовать

1. **Запустить приложение**: Дважды щелкните файл `start_player.bat`, чтобы запустить приложение
2. **Загрузить плейлист**: Нажмите «Выбрать плейлист» и выберите:
   - JSON-файл с путями к видео и диапазонами пропуска
   - Текстовый файл с путями к видео (по одному на строку)
3. **Управление воспроизведением**: Используйте элементы управления плеером для перехода между видео и управления воспроизведением

## Форматы плейлистов

### JSON-формат
```json
[
  {
    "video": "path/to/video.mp4",
    "skipRanges": [
      [0, 15],      // Пропустить с 0:00 до 0:15
      [150, 165]    // Пропустить с 2:30 до 2:45
    ]
  }
]
```

### Текстовый формат
```
path/to/video1.mp4
path/to/video2.mp4
path/to/video3.mp4
```

## Требования

- Windows 11
- Python (должен быть предустановлен в большинстве систем)
- Современный веб-браузер (Chrome, Firefox, Edge и т.д.)

## Включенные файлы

- `start_player.bat` - Скрипт запуска для старта сервера и открытия плеера
- `index.html` - Основной интерфейс видеоплеера
- `server.py` - Сервер на Python для обслуживания веб-страницы
- `playlist.json` - Пример JSON-плейлиста с правилами пропуска
- `playlist.txt` - Пример текстового плейлиста
- `videos/` - Папка для размещения видеофайлов
- `README_RU.md` - Этот файл

## Как это работает

1. BAT-файл запускает простой HTTP-сервер Python на порту 8000
2. Автоматически открывается видеоплеер в вашем браузере по адресу `http://localhost:8000/index.html`
3. Плеер позволяет загружать плейлисты и определять правила пропуска
4. Во время воспроизведения плеер автоматически пропускает определенные временные диапазоны
5. Области пропуска визуально обозначены красными маркерами на таймлайне

## Режим чистого интерфейса

Для использования с OBS или другими инструментами захвата экрана вы можете запустить плеер в режиме чистого интерфейса, добавив параметр `?clean=1` к URL:
`http://localhost:8000/index.html?clean=1`

В этом режиме элементы управления будут скрыты, и курсор мыши будет скрыт для удобства захвата экрана.

## Устранение неполадок

- Если приложение не запускается, убедитесь, что Python установлен и доступен из командной строки
- Если видео не загружаются, проверьте правильность путей к файлам в вашем плейлисте
- Для локальных файлов используйте относительные пути от каталога приложения
