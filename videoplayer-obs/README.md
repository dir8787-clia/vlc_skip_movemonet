# OBS Видеоплеер

Локальное веб-приложение для стриминга видео через OBS, полностью автономное, запускаемое одним кликом в Windows 11.

## Особенности

- Чтение плейлистов в формате Extended M3U
- Поддержка онлайн- и офлайн-загрузки плейлистов
- Редактирование, сохранение и автоматическое восстановление правил пропуска фрагментов
- Возможность скрывать/показывать элементы управления

## Запуск в Windows 11

1. Убедитесь, что на вашем компьютере установлен Python
2. Дважды щелкните по файлу `запуск.cmd`
3. Приложение откроется в браузере по адресу http://localhost:8000

## Использование

### Загрузка плейлиста

- **Локальный файл**: Нажмите "Выбрать локальный файл" и укажите .m3u файл
- **Удалённый URL**: Введите URL-адрес плейлиста в поле и нажмите "Загрузить по ссылке"

### Управление воспроизведением

- "Предыдущее" / "Следующее" - переключение между видео
- "Пауза" - приостановка/возобновление воспроизведения

### Редактирование пропусков

1. Нажмите "Редактировать пропуски"
2. Используйте "Добавить пропуск с текущей позиции", чтобы создать новое правило
3. Редактируйте или удаляйте существующие правила
4. Нажмите "Сохранить как JSON-файл", чтобы экспортировать правила

### Скрытие/показ управления

- Нажмите "Скрыть управление" / "Показать управление"
- Используйте клавишу `H` для переключения
- Добавьте `?clean=1` или `?obs=1` к URL для автоматического скрытия управления

## Форматы

### Extended M3U

```
#EXTM3U
#EXTINF:0,Название видео
http://example.com/video.mp4
```

### Правила пропуска (JSON)

```json
{
  "Название видео": [
    [начало_сек, конец_сек],
    [10, 25],
    [45, 60]
  ]
}
```

## Совместимость с OBS

При использовании параметра `?clean=1` или `?obs=1` приложение переходит в режим для OBS:
- Скрытие всех элементов управления
- Видео на весь экран
- Отсутствие отступов и полос прокрутки
