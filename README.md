# Стриминговый видеоплеер для OBS

Автономное локальное веб-приложение для стриминга видео через OBS с возможностью пропуска фрагментов.

## Особенности

- Две страницы: панель управления (index.html) и чистый плеер (player.html)
- Поддержка плейлистов в формате Extended M3U (.m3u)
- Загрузка как локальных файлов, так и по URL
- Редактор пропусков с возможностью сохранения в JSON
- Синхронизация между страницами через URL-параметры
- Режим для OBS (clean mode) с отключенными элементами управления
- Автоматическое сохранение настроек в localStorage

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.6 или выше
2. Распакуйте архив с приложением
3. Запустите файл `запуск.cmd` (для Windows)
4. Автоматически откроется главная страница приложения по адресу http://localhost:8000

## Использование

1. Загрузите плейлист:
   - Локальный файл .m3u через кнопку "Загрузить .m3u (файл)"
   - По URL через кнопку "Загрузить по URL"

2. Для использования в OBS:
   - Нажмите "Открыть плеер в новом окне"
   - В окне плеера будет воспроизводиться текущее видео
   - Используйте URL `http://localhost:8000/player.html?clean=1` в качестве Browser Source в OBS

3. Для редактирования пропусков:
   - Выберите видео в плейлисте
   - В разделе "Редактировать пропуски" добавляйте/удаляйте временные метки
   - Используйте кнопку "Добавить пропуск с текущей позиции" во время воспроизведения

## Горячие клавиши

- Клавиша `H` в окне плеера: переключение видимости элементов управления

## Совместимость

- Chrome и Edge (современные версии)
- Работает в Windows 11

## Безопасность и CORS

При загрузке плейлистов по URL могут возникнуть проблемы с CORS. Возможные решения:

1. Загрузите файл .m3u локально
2. Запустите браузер с флагом `--disable-web-security` (только для разработки!)
3. Настройте сервер для разрешения CORS

## Технические детали

- Только vanilla HTML/CSS/JavaScript (без фреймворков)
- Все данные хранятся локально в localStorage
- Автоматическое восстановление настроек при перезапуске
- Защита от случайного закрытия окна плеера
- Оптимизированная проверка пропусков (каждые 200мс)
