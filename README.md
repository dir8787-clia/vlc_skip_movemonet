# OBS Видеоплеер

Автономное веб-приложение для стриминга видео через OBS с возможностью автоматических пропусков таймингов.

## Особенности

- Поддержка загрузки плейлистов M3U (локальных и по URL)
- Автоматические пропуски заданных таймингов
- Встроенный редактор пропусков
- Режим для OBS (скрытие интерфейса)
- Сохранение настроек между сеансами
- Полностью на русском языке

## Требования

- Python 3.6 или выше
- Современный браузер (Chrome, Edge)

## Установка и запуск

1. Убедитесь, что Python 3.6+ установлен в системе и доступен из командной строки
2. Дважды щелкните по файлу `start_player.cmd` (или `start_player.ps1` для PowerShell)
3. Приложение автоматически откроется в браузере по адресу http://localhost:8000/player.html

## Использование

### Загрузка плейлиста

- **Локальный файл**: Нажмите "Обзор" и выберите файл .m3u
- **URL**: Введите адрес плейлиста (например, http://192.168.0.29:8090/12.m3u) и нажмите "Загрузить"

### Управление воспроизведением

- "Предыдущее"/"Следующее" - навигация по плейлисту
- "Редактировать пропуски" - открытие редактора таймингов
- Клавиша `H` - переключение видимости интерфейса

### Режим OBS

- Добавьте `?clean=1` или `?obs=1` к URL для автоматического скрытия интерфейса
- Или нажмите "Скрыть управление" во время работы

### Редактор пропусков

- Просмотр и редактирование текущих пропусков
- Добавление пропусков с текущей позиции видео
- Сохранение правил в формате JSON

## Формат плейлиста M3U

Поддерживается Extended M3U формат:
```
#EXTM3U
#EXTINF:0,Название видео
http://адрес.сервера/путь/к/видео
```

## Формат правил пропуска

Правила сохраняются в формате JSON:
```json
{
  "Название видео": [
    [0, 15],
    [120, 135]
  ]
}
```
Где числа - время в секундах начала и конца пропуска.

## Безопасность

При загрузке плейлистов по URL может возникнуть ошибка CORS. Возможные решения:
1. Загрузите плейлист локально
2. Запустите браузер с флагом `--disable-web-security` (не рекомендуется для постоянного использования)
3. Настройте CORS на сервере плейлиста
